# Actividad 9 — Control de acceso vehicular con IA

**Gestión de proyectos de inteligencia artificial · Módulo 3 / Semana 11**

Caso académico **simulado** para analizar escalabilidad en la nube, optimización FinOps y gobernanza responsable de una solución de visión computacional para accesos vehiculares.

## Entregables
- Reporte técnico PDF: análisis y rediseño, métricas, costos, auditoría ética/técnica/legal y plan responsable.
- Anexo técnico XLSX: escenarios de costos, métricas y fairness sintético.
- Dos diagramas PNG: arquitectura base hipotética y arquitectura híbrida propuesta.
- ZIP académico con los entregables.

**Importante:** el paquete PDF/XLSX/PNG/ZIP está preparado para descarga en la conversación; los archivos binarios todavía **no se han subido a este repositorio**. Los archivos Markdown y CSV publicados aquí permiten revisar supuestos y trazabilidad.

## Advertencias metodológicas
No existen benchmarks reales, costos cotizados ni pruebas productivas. La simulación arroja falsos positivos superiores al umbral objetivo, por lo que **no demuestra que el sistema sea apto para abrir barreras de forma automática**. El sistema requeriría calibración, evaluación independiente y controles de seguridad física antes de cualquier uso real.
